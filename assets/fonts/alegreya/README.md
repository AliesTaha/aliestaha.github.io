# Alegreya webfonts

Self-hosted Latin subsets for the personal journal. Downloaded unchanged from
Google Fonts on 2026-10-04. Both faces are weight 400 and WOFF2 with TrueType
outlines; use `font-style: normal` or `italic` as indicated by the filename.

| File | Style | Bytes |
| --- | --- | ---: |
| `alegreya-latin-400-normal.woff2` | normal | 22,888 |
| `alegreya-latin-400-italic.woff2` | italic | 23,236 |

Official CSS request:
<https://fonts.googleapis.com/css2?family=Alegreya:ital,wght@0,400;1,400&display=swap>

The request used a modern browser User-Agent to obtain WOFF2, and only the
two blocks marked `latin` were selected:

- Normal: <https://fonts.gstatic.com/s/alegreya/v41/4UacrEBBsBhlBjvfkQjt71kZfyBzPgNG9hU4-6qjkySFrt19.woff2>
- Italic: <https://fonts.gstatic.com/s/alegreya/v41/4UaSrEBBsBhlBjvfkSLk3abBFkvpkARTPlbgv5qhmSWnqsV8_9Q.woff2>

Google Fonts declares this Unicode range for both files:

```text
U+0000-00FF, U+0131, U+0152-0153, U+02BB-02BC, U+02C6, U+02DA,
U+02DC, U+0304, U+0308, U+0329, U+2000-206F, U+20AC, U+2122,
U+2191, U+2193, U+2212, U+2215, U+FEFF, U+FFFD
```
